# EcoWattSense testing evidence

Index page for the Week 10 Testing Evidence Pack of Group 12 (Sector 12), module M3W226703.

- Page: https://gcu-sector-12.github.io/ecowattsense-testing-evidence/
- Project code: https://github.com/GCU-Sector-12/ecowattsense

The page is only an index. It has one row per team member. Each row links to one PDF with that person's evidence. The PDF files stay in the Teams files of the group. You need a GCU sign-in to open them.

## How to add your PDF

1. Save your section of the evidence pack as a PDF.
2. Upload the PDF to the Teams files of the group.
3. Copy the link to the file (Share, Copy link).
4. Send the link to Dariusz on Discord. He puts it in your row.
